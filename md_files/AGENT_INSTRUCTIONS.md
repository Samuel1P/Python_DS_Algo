# Agent Instructions for Python DS & Algo Project

## Project Overview
This is a learning-focused Python project for Data Structures and Algorithms practice.

## Coding Standards

### General Guidelines
- Follow PEP 8 style guidelines
- Use descriptive variable and function names
- Add docstrings for all functions and classes
- Include type hints where appropriate
- Write clear, readable code with comments

### File Organization
- Keep related algorithms in appropriate subdirectories
- Use descriptive filenames (e.g., `bubble_sort_recursion.py`)
- Maintain consistent naming conventions

### Testing Requirements
- Write comprehensive test cases for all implementations
- Use pytest for testing
- Test edge cases and boundary conditions
- Ensure all tests pass before submitting code

### Code Structure
- Implement both iterative and recursive solutions when applicable
- Include time and space complexity analysis
- Add example usage in docstrings
- Keep functions focused and single-purpose

### Problem-Solving Approach
1. Understand the problem thoroughly
2. Plan the solution approach
3. Consider time and space complexity
4. Implement the solution
5. Test with various inputs
6. Optimize if necessary

## Project-Specific Guidelines

### Data Structures
- Implement from scratch when possible
- Include both basic and advanced operations
- Document the interface clearly

### Algorithms
- Provide multiple implementations (iterative/recursive)
- Include complexity analysis
- Add visual examples when helpful

### Problem Solutions
- Follow the problem-solving template
- Include test cases
- Document the approach taken

## Quality Checklist
- [ ] Code follows PEP 8
- [ ] Functions have docstrings
- [ ] Type hints are included
- [ ] Tests are comprehensive
- [ ] Edge cases are handled
- [ ] Complexity is documented
- [ ] Code is readable and well-commented

## Common Patterns
- Use `if __name__ == "__main__":` for example usage
- Include example inputs and expected outputs
- Use meaningful variable names
- Break complex problems into smaller functions
